# Icons

One library: **Lucide**, stroke 1.75, sizes 16 (inside text and badges), 20 (buttons, list rows), 24 (navigation, headers). Icons take the colour of the text next to them.

An icon may stand alone only if it is one of the universal symbols below; every other icon has a visible label, and every icon-only button has an accessible name.

## Universal (may stand alone)

| Action | Lucide |
|---|---|
| Back | `ArrowLeft` |
| Close a modal page, sheet, banner | `X` |
| Search | `Search` |
| Add | `Plus` |
| More actions | `Ellipsis` (horizontal) |
| Notifications | `Bell` |
| Cart | `ShoppingBag` |
| Settings | `Settings` |
