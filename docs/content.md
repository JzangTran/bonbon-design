# Content

Words are part of the interface. bonbon talks like a helpful neighbour: plain, warm, specific, never cute when something went wrong. The voice stays the same; the tone follows the moment (Mailchimp).

## The formula

Every message answers three questions, in this order:

1. **What happened** (or what is wrong), with the user's own data.
2. **What it means for them.**
3. **What to do next**, or what happens next and when.

Ask "Thành công rồi thì sao?" of every confirmation. If the message cannot answer it, it is not finished.

## Errors (Polaris, NN/g)

- Put the message next to the problem; keep what the user typed.
- Name the exact problem in everyday words. No error codes, no "invalid", no "lỗi hệ thống" (codes go in a details line for support).
- Give a fix that takes as few steps as possible; offer the fix as a button when the system can do it.
- Do not blame ("bạn đã nhập sai"); describe the field ("Số điện thoại cần 10 chữ số").
- No jokes in errors.

## Labels and buttons

- Verb + object: **Lưu món**, **Nhận đơn**, **Thêm địa chỉ**. Never "OK", "Xác nhận", "Gửi" alone when a precise verb exists.
- The button that finishes a step says what it does, not where it goes: **Đặt món · 95.000 ₫**, not "Tiếp tục".
- Destructive buttons say what is destroyed: **Xoá món**, **Đóng quán**.
- Field labels are nouns, always visible above the field; placeholders show an example, never the label.

## Conventions

| Thing | Write |
|---|---|
| Money | 95.000 ₫ (dot thousands, space, ₫) |
| Time | 14:02 · 15–20 phút |
| Date | 20/11 · 20/11/2026 when the year differs |
| Distance | 350 m · 1,2 km |
| Order | #1025 |
| Bank account | VietinBank ••5264 |
| Address the user | "bạn" |
| Shop | "quán" |
| Us | avoid "chúng tôi" in the product; "bonbon" when needed |

Sentence case. No exclamation marks except a first-time celebration. Numbers as digits.

## Empty states

An empty state says what will appear here, why it is empty now, and the one action that fills it. "Chưa có đơn nào. Đơn mới hiện ở đây ngay khi khách đặt; bật âm báo để không bỏ lỡ." + **Bật âm báo**.
